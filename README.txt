Як опублікувати
  Завантажте весь вміст цієї папки (разом із папкою images) у кореневу
  папку сайту на сервері (часто вона називається public_html або www).
  Нічого встановлювати не треба: це звичайні HTML-файли.
  Підійде будь-який хостинг, а також безкоштовні GitHub Pages чи Netlify.

Як змінювати текст
  Кожна сторінка — окремий файл. Відкрийте його в будь-якому текстовому
  редакторі, змініть текст між тегами і збережіть. Меню й футер
  повторюються на кожній сторінці, тож якщо міняєте їх, міняйте у всіх семи файлах.
